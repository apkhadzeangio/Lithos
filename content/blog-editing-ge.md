# LITHOS-ის ბლოგი

სტატიების საწყისი ტექსტებია `content/blog.json`-ში. გვერდებს ქმნის `scripts/build-blog.mjs`, საერთო ჩარჩო კი `src/blog.html`-შია. დიზაინი და ძებნა ინახება `dist/blog/blog.css` და `dist/blog/blog.js` ფაილებში. ფოტოები გამოყენებულია საიტის არსებული ნამუშევრების გალერეიდან; კონკრეტული მასალა ამ ფოტოებით არ არის დადასტურებული.

ტექსტის შეცვლის შემდეგ გაუშვით:

```sh
node scripts/build-public-pages.mjs
node --test tests/blog.test.mjs
```

გენერატორი აახლებს ბლოგის სიას, ხუთ სტატიის გვერდს, მთავარი გვერდის სამ ბარათს, საერთო მენიუს და sitemap-ს. შესანახია როგორც წყაროები, ისე გენერირებული `dist` ფაილები: არსებული GitHub Pages workflow საიტს `dist`-იდან აქვეყნებს `main`-ზე ცვლილების მოხვედრის შემდეგ.

თითოეულ სტატიას აქვს უცვლელი `slug`, სათაური, თემა, თარიღი, ფოტო, მოკლე აღწერა, შესავალი, სექციები, პრაქტიკული რჩევა, შემაჯამებელი სია და წყაროების ბმულები. სექციის `id` უნიკალური უნდა იყოს სტატიის ფარგლებში. ძებნა აერთიანებს სათაურს, თემასა და მოკლე აღწერას; სტატიები JavaScript-ის გარეშეც იკითხება.

თარიღები ტექსტის გამოქვეყნებისას შეგნებულად შეასწორეთ. მოვლის რჩევების განახლებისას გადაამოწმეთ კონკრეტული მასალის მწარმოებლის მოქმედი ინსტრუქცია. ფოტოებისთვის საჭიროა ძირითადი `.webp` და შესაბამისი `.thumb.webp` ვერსია.

შემოწმებულია სიისა და სტატიის გვერდები 1280 და 360 პიქსელის სიგანეზე, თემის ფილტრი, მრავალსიტყვიანი ძებნა, ცარიელი შედეგი და გასუფთავება, სარჩევი, ლოკალური ფოტოები, მეტამონაცემები, sitemap და GitHub Pages-ის ქვემისამართებზე ბმულების გადაწერა.
